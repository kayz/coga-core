# Public-example sanitization rules

This example is intentionally safe to publish.

## Allowed

- Public laws, regulator publications, open standards, and public platform docs.
- Generic broker-channel concepts and architectural invariants.
- Entirely fictitious applications and stable abstract contract identifiers.
- Example organization policies explicitly marked as replaceable.

## Excluded

- Real product or organization names, domains, endpoints, repository links, account
  identifiers, screenshots, secrets, certificates, and environment bindings.
- Copied private requirements, UI text, navigation trees, data samples, or issue and
  incident details.
- Exact entitlement amounts, business thresholds, internal risk classifications,
  or operating schedules.
- Proprietary API paths, schemas, error codes, vendor agreements, or implementation
  details.

Before publication, scan the full directory and review the diff. A source URL is
not permission to reproduce source text; artifacts summarize the resulting rule and
retain only the title and link needed for provenance.
